# ⚡ IIIAK Study Platform & Ecosystem

> **منصة IIIAK التعليمية الفائقة الذكاء** — بيئة متكاملة لبناء الكورسات، تلخيص المحاضرات، وتوليد الامتحانات والفلاش كاردز التفاعلية بالذكاء الاصطناعي.

---

## 🚀 المميزات الرئيسية (Core Features)

- 🧠 **AI Course & Exam Generator**: توليد كويزات ذكية وامتحانات متقدمة من ملفات الـ PDF والسلايدات.
- ⚡ **Interactive Flashcards**: نظام مراجعة تكرار متباعد (Spaced Repetition) لتثبيت المعلومات.
- 📊 **Smart Telemetry & Analytics**: متابعة دقيقة لمستوى الطالب ونقاط القوة والضعف ومعدل التقدم.
- 👥 **Study Groups & Social Learning**: غرف مذاكرة جماعية، تحديات كويز لايف بين الطلاب، وشات تفاعلي.
- 🛡️ **Ultra-Secure Architecture**: طبقات حماية صارمة وصلاحيات أدمن متقدمة مع Firebase و Vercel.
- 📱 **Multi-Platform Support**: دعم PWA كامل مع إمكانية التثبيت السريع على أندرويد و iOS وسطح المكتب.

---

## 🛠️ البدء والتشغيل (Getting Started)

### 1. تثبيت الاعتماديات (Install Dependencies)
```bash
npm install
```

### 2. التشغيل في بيئة التطوير (Development Mode)
```bash
npm run dev
```

### 3. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
```

---

## 🔒 إعدادات الحماية والبيئة (Environment Setup)

قم بإنشاء ملف `.env.local` لإعدادات Firebase و AI APIs:

```dotenv
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
VITE_GEMINI_API_KEY=
```
